# x_thread.md — X Thread

## Hard Constraints (X and LinkedIn only)

- Sentences range from 150-200 characters.
- Hard line break after every sentence unless inside a list.
- No emojis.
- No em dashes, long dashes, or double hyphens used as dashes.
- No corporate language, filler phrases, or throat-clearing.
- Never start with "I" as the first word.
- Write like a person, not a brand account.

---

## Hard Rules

- Tweet 1 is the hook — must standalone as a great post
- Never start tweet 1 with "I" or "Thread:"
- Never start tweet 1 with "A thread on..."
- Each tweet must be readable without the others
- No tweet exceeds 280 characters
- End tweet closes the loop opened in tweet 1
- One CTA in the final tweet only

---

## Thread Structure

### The 5-Tweet Thread (default)
Tweet 1: Hook — the bold claim or result
Tweet 2: Context — why this matters
Tweet 3: The framework or system (the meat)
Tweet 4: Proof — real example, number, or story
Tweet 5: Close — reframe plus single CTA

### The 7-Tweet Thread (for frameworks)
Tweet 1: Hook
Tweet 2: The problem most people have
Tweet 3: Why the common solution fails
Tweet 4: The framework part 1
Tweet 5: The framework part 2
Tweet 6: Real proof or example
Tweet 7: Close plus CTA

### The Story Thread (for building in public)
Tweet 1: Hook — the outcome or the moment
Tweet 2: Where it started (the before)
Tweet 3: The turn — what changed or went wrong
Tweet 4: What was learned
Tweet 5: The framework extracted from the story
Tweet 6: How to apply it
Tweet 7: Close plus CTA

---

## Tweet 1 Rules (the hook tweet)

Must work as a standalone post.
Must contain the core idea in full.
Must be specific — number, result, or bold claim.
Must create enough tension to demand resolution.

Must not start with "I" or "Thread:".
Must not be longer than 240 characters.
Must not promise something the thread doesn't deliver.

---

## Hook Tweet Patterns

"[Specific result or number].

[The transferable insight in one sentence.]

[Promise of what's in the thread]:"

---

"[Counter-intuitive truth].

[One sentence agitation.]

[Promise of the proof or framework]:"
