# x_post.md — X Short Form Post

## Hard Constraints (X and LinkedIn only)

- Sentences range from 150-200 characters.
- Hard line break after every sentence unless inside a list.
- No emojis.
- No em dashes, long dashes, or double hyphens used as dashes.
- No corporate language, filler phrases, or throat-clearing.
- Never start with "I" as the first word.
- Write like a person, not a brand account.

---

## Hard Rules

- 280 characters max for the post body
- Never start with "I"
- No hashtags unless explicitly requested
- No emojis unless explicitly requested
- One idea only
- No links in the post body (kills reach)
- CTA goes in first reply if needed

---

## Structure

### Pattern 1: The Provocative Truth
[Bold claim.]
[One sentence proof or expansion.]
[One sentence implication or CTA.]

### Pattern 2: The Contrast
[Most people do X.]
[The ones that win do Y.]
[Here's why.]

### Pattern 3: The Specific Result
[Real number or outcome.]
[The one mechanic that drove it.]
[The lesson.]

### Pattern 4: The Reframe
[Common belief stated plainly.]
[The flip.]
[What that means for you.]

### Pattern 5: The Short Punch
[One sentence. That's it.]

---

## Hook Rules

The first line must do one of:
- State a truth most people avoid
- Lead with a specific number or result
- Create a pattern interrupt
- Make the reader feel seen

First line character budget: 60-80 chars max.
If the post stopped after line one — would it still land?
If yes — strong hook. If no — rewrite the first line.
