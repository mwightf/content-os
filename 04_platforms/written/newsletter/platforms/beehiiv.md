## Modular Section Structure
Beehiiv is built for modular newsletters.
Use section headers consistently each issue.

Suggested recurring sections:
- The main piece
- One tool or resource worth knowing
- One thing from the community
- The CTA

## Sponsor Slot Placement
If running sponsors: after section 1, before section 2.
Write sponsor copy in the brand voice from
01_brand/voice_and_tone.md.
Only sponsor products the brand actually uses.
