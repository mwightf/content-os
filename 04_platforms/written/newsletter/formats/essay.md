# essay.md — Newsletter Essay Format

## Purpose
For issues built around a single argument or framework.
No story wrapper needed. The idea carries itself.
The default format when nothing else clearly fits.

---

## When to Use

- Framework or system explanations
- Contrarian takes that need full development
- Pillar content that needs depth
- Any issue where the insight is the point

---

## Structure

**Subject line:**
States the argument or framework directly.
"The [TOPIC] System, Explained."
"Why [Belief A] Beats [Belief B] Every Time."

**Opening hook (3-5 lines):**
State the argument immediately.
No story setup.

Example pattern:
"Most [things] fail before they start.
Not because [common reason].
Because [reframed reason]."

**Section 1 — The problem (2-3 paragraphs):**
What's broken about the conventional approach.
Name the wrong belief. Show what it costs.

**Section 2 — The reframe (2-3 paragraphs):**
The new way of seeing it.
Ground it in a real example or proof point.

**Section 3 — The framework (2-3 paragraphs):**
How to apply the reframe.
Specific, actionable, replicable.

**Section 4 — The proof (1-2 paragraphs):**
Real evidence the framework works.
Pull from the fact bank in 01_brand/brand_index.md.

**Close plus CTA:**
One sentence that lands the core argument again.
One CTA.

---

## Length
700-1000 words.
